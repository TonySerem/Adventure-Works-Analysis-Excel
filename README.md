## Adventure Works Sales Analysis

## Project Overview
This project analyzes Adventure Works sales data using Microsoft Excel to create visual representations of the data to assess the company's 
performance over four years. The analysis is primarily intrested on profit,Specifically, on the analysis of 
products, customer locations(countries), and the time trends to identify any patterns or trends.
